# Demo Images

Synthetic, AI-generated faces for exercising the `POST /analyze` workflow and the
browser workbench without using any real person's photo.

## Source and License

These images were generated by [thispersondoesnotexist.com](https://thispersondoesnotexist.com/),
which produces StyleGAN2 faces of people who do not exist. They depict no real
individual, carry no identity, and have no copyright tied to a real subject, so
they are safe to commit to a privacy-first project.

This does not change the repository rule for real photos: **do not commit real
face images.** Synthetic faces are the only face images this repository tracks.

## Usage

Use any of these as the upload for a local or public `/analyze` call.

```powershell
# Local API (see the main README for setup)
$ImagePath = "docs/demo-images/synthetic-face-1.jpg"
curl.exe -s -F "file=@$ImagePath" http://127.0.0.1:8000/analyze
```

Or pick one in the browser workbench at `/` via **Choose local image**.

Each should return `face_detected: true`, MediaPipe model metadata, geometric
ratios, and the landmark-derived visualization geometry. The API returns
technical geometry only and never an attractiveness, identity, medical, or
personality judgment.

## Refreshing

To regenerate, fetch a new synthetic face (each request returns a different one):

```powershell
$ua = "Mozilla/5.0 (Windows NT 10.0; Win64; x64) AppleWebKit/537.36"
Invoke-WebRequest -Uri "https://thispersondoesnotexist.com/" `
  -OutFile "docs/demo-images/synthetic-face-1.jpg" -UserAgent $ua
```

Confirm the result has exactly one clearly visible, frontal face before
committing, so the demo stays a clean single-face example.
